The week it runs on

The commitment is made once a week and checked once, which is what keeps the daily interaction under ten seconds

Four decisions that shaped it

Every habit app I tried scored me, and a bad week wiped the number back to zero, which is the week you're most likely to quit

Consistency is a weighted count

Older days count for less, so one from a fortnight ago is worth half of today. The number follows how you are behaving now rather than how long an unbroken run has survived.

The denominator is delivered reminders

A day when no reminder was actually sent drops out of the count, which is why the two figures differ. It keeps the number measuring what you did rather than whether the notification got through.

A day has five states

All, part, none, no answer, and no reminder sent. Recording that nothing happened is a different state from never opening the app, and collapsing the two would lose the difference between a bad week and someone who has stopped.

Goals are a run rate

You set a count and a date, and the progress comes from entries you are already making, so there is nothing extra to fill in. What it shows you is the rate needed from here, not a percentage or a grade.

Four surfaces, kept in step

A phone, a desktop browser, the Mac menu bar and a notification all have to say the same thing about the same day, and the fourth one below is the same Apps Script file laying itself out again

Ninety-one days, one cell each

24named lanes in the build gate, run before anything ships
462invariants enforced by a lane, of 594 registered
4surfaces photographed on every run, from the shipped code

The surfaces lane will not accept a green build on trust: it wants a fresh screenshot of each of the four every run, and fails on the one that has none. The Mac panel is rendered out of the shipped Swift rather than mocked, so a screenshot cannot be a lie about the type or the layout. A rule that has been written but not yet built is recorded as pending rather than quietly missing, which is why 594 and 462 are both on the board.
